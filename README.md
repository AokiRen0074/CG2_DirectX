# CG2_評価課題加点要素

## 三角形を動かす
ImGuiからパラメーターを操作し、オブジェクトのスケール、回転、平行移動をリアルタイムに反映させる仕組みを構築した

## Textureを張る
ポリゴンに対して画像を貼り付けて、正しく表示させるための処理の実装をした

## DepthBufferの利用
複数のオブジェクトが重なった際に、前後関係が正しく描画されるように、DepthBufferを有効化した

## Textureの動的切り替え
実行中にオブジェクトに貼られているテクスチャを別の画像に切り替える処理を実装した

## 三角形を利用した映像演出
三角形のポリゴンを大量のパーティクルに見立てて、空間の奥行きやライティングを活用させた映像演出を作成した。

# デバッグカメラについて
マウスホイールでオブジェクトに近づいたり離れることができる
左クリックで中心を見つめたまま回り込むように移動できる

# 映像演出への切り替え
スペースで映像演出へ切り替え、スペースで加点要素へ切り替え
