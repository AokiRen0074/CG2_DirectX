### PathTracing
レイトレーシングはみんなやりそうだからパストレーシングを実装しました。

3DCGのテスト環境でよく使われるコーネルボックスをシェーダー内で作り、パストレーシングを視覚的にわかりやすくしました。
ノイズがすごい出るため、フレーム間で過去のレンダリング結果を保持、加算し続けるプログレッシブレンダリングのアーキテクチャを設計しました。
また、ノイズを消すために完全なランダムの反射ではなくコサイン重み付き半球サンプリングをを実装しました。
重点サンプリングを行い、レンダリングにおける計算の収束速度を向上させました。
sinなどで乱数を作るのではなく、PCG Hashを導入し完全な一様分布を持つ乱数を生成しています。
白飛びを防ぐためにACESトーンマッピングを実装しました。
