現在のゲーム背景は、最初のイメージに合わせた結晶のみのシンプルな構成です。足場の形と色は維持しています。以下に記載した遺跡・岩柱・岩島のモデルは保存されていますが、ゲームには表示していません。

# 足場と多層背景

Blenderで作成し、ゲームへ反映済みです。プロジェクト内では `Resources/AL4/Runtime/` に保存しています。

## 足場

元のAL4の足場から輪郭を取り、薄い端と深く欠けた下面の形を再現しました。上面は平らで、青灰色の上面・青い縁・濃紺の側面を維持しています。

短・中・長の3種類を `ground_short.obj`、`ground_normal.obj`、`ground_long.obj` に書き出しています。幅と上面の基準位置は既存のステージに合わせています。

## 背景

- `background_arch.obj`：大きく壊れた環状の遺跡。
- `background_spires.obj`：高さが異なる遠景の岩柱群。
- `background_island.obj`：不規則に欠けた浮遊岩島。
- `background_crystal.obj`：近い層の結晶。

遠くの遺跡、岩柱、岩島、結晶の順に奥行きを分け、カメラに対して異なる速度で流れます。背景はプレイヤーの後ろへ描画し、足場との色の差を保っています。

## BlenderとOBJ

`StageEnvironment.blend` に7種類の元モデルが入っています。Blender内では編集しやすいように配置と倍率を変えています。OBJは各モデルの原点を基準にした座標で出力し、ゲーム側で配置と倍率を設定しています。

OBJと同名のMTLを一緒に置いてください。外部テクスチャは不要です。現在のゲームローダーに合わせ、三角形化・材質ごとのメッシュ分割・X反転の補正を行っています。

## 確認

7モデルの閉じた形状・三角形・法線・材質参照を確認しました。足場の輪郭が元のAL4のデータに一致すること、上面がY=0であることも検証しています。

Debug／Developmentのビルドと、通常ステージ・ボスエリアの描画・正常終了を確認しています。操作・当たり判定・攻撃と軌跡の形は変更していません。
