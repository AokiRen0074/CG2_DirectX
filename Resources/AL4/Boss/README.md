# Blender製ボスモデル

黒銅色の装甲と橙色の結晶を組み合わせた、浮遊型ボスのモデルです。ゲーム内のボスに反映済みです。ゲームを起動して **F6** を押すとボス練習へ移れます。

## ファイル

- `PrismBoss.blend`：Blender 5.1の編集用データ。
- `boss_core.obj` / `boss_core.mtl`：中心の本体・結晶・発光部分。
- `boss_emitter.obj` / `boss_emitter.mtl`：前面の槍型パーツ。
- `boss_armor.obj` / `boss_armor.mtl`：周囲の装甲。ゲームでは4枚に複製して使用します。
- `PrismBoss_preview.png`：Blenderでの確認画像。
- `game-boss.png`：通常時のゲーム画面。
- `game-phase.png`：第二形態への移行中のゲーム画面。

プロジェクト内の保存先は `Resources/AL4/Boss/` です。OBJとMTLは同じフォルダーに置きます。外部テクスチャは不要です。

## Blenderで編集

`ASSEMBLY | editable preview` に完成状態のパーツが入っています。中心・前面・装甲はそれぞれ分かれており、パーツを選択して形や材質を編集できます。

`BOSS 01`～`BOSS 03` は書き出し元のパーツです。完成表示と重ならないように非表示にしています。`STUDIO` は確認用のカメラ・照明・床で、ゲーム用OBJには含んでいません。

本体64、前面52、装甲1枚27の合計224三角形でゲームに表示します。OBJは三角形化し、マテリアル単位でメッシュを分割しています。現在のゲームローダーのX反転に合わせて書き出したため、別のビューアーでは左右の向きが異なって見える場合があります。

## ゲームへの反映

本体・前面パーツ・4枚の装甲が新しいOBJを読み込みます。既存の回転、攻撃予告時の装甲の開閉、第二形態での展開を使用し、HP・攻撃パターン・当たり判定は変更していません。

発光はOBJの実際の面と材質に沿って描画し、既存のブルームで合成しています。

## 検証

OBJの頂点・三角形・法線の向き・材質参照を確認済みです。Debug／Developmentビルド、通常時と第二形態への移行時の描画・正常終了を確認しています。
