# 床・敵・チュートリアルの調整

- 床を上・下・横から当たる固体に変更。上向きの突進や速い移動でも床をすり抜けないように、移動前後の区間で判定します。
- 敵は一種類に統一。以前の上突き・下突き限定の条件をなくし、どの方向の攻撃でも倒せます。F3の種類選択も削除しました。
- 現在保存されている床・敵の位置、チェックポイント、ボス開始位置を維持しています。
- 最初の小さな穴の前に「ジャンプ」、最初の敵の上に「敵を倒すと 空中ジャンプ＋1」、空中の敵が続く区間に「倒して、もう一度ジャンプ」と表示します。
- 空中で敵を倒して回数が回復した瞬間にも、プレイヤーの近くへ「空中ジャンプ＋1」と表示します。回復は従来どおり1回、上限3回です。

案内はPNGリソースです。F4の **tutorial** ページで選び、**World position** からステージ内の位置、**Position** から画面上の微調整、**Size** から表示サイズを変更できます。進むと案内が画面から離れ、距離に合わせて薄くなります。

検証では、通常ジャンプで最初の穴を越えて着地できること、床の下・横・高速移動時の衝突、床の継ぎ目、敵を倒したときの1回回復、現在の空中の敵をつないで向こう岸まで渡れることを確認しています。
