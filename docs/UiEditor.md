# UIエディター

Debug版を起動して **F4** を押すと開きます。もう一度F4、または `Return to game` でゲームに戻ります。編集中はゲームとタイム計測が止まります。

## 編集

- 上の `title / hud / boss / impact / clear / transition` でプレビューを切り替えます。クリアしていなくても結果画面を編集できます。
- 左の画面で要素をクリックし、ドラッグして移動します。右下の水色の四角をドラッグするとサイズが変わります。
- 右の一覧からも選択できます。背面のパネルや細い線、非表示の要素も選べます。
- 右の `Position`、`Size`、`Pivot`、`Tint / alpha` で位置・サイズ・基準点・色・透明度を調整します。数値欄はCtrl+クリックで直接入力できます。
- `PNG asset` で画像を差し替えます。`Add image / Add text` で追加、`Duplicate` で複製、`Delete` で削除できます。
- `Layer back / Layer front` で重なり順を変えます。
- Shiftを押しながらドラッグすると8ピクセル刻みになります。画面上で選択後、矢印キーで1ピクセル、Shift+矢印で8ピクセル動かせます。
- `Undo / Redo` またはCtrl+Z / Ctrl+Yで取り消し・やり直しができます。

回避・貫通・回数回復などの一時的な表示は、一覧からその要素を選択するとプレビューに表示します。

## 保存

**Save またはCtrl+S** で保存します。保存しなくても現在のゲームには編集結果が反映されますが、再起動後にも残すには保存が必要です。未保存の変更があるとウィンドウ名に `*` が付きます。

配置データはプロジェクトの **Resources/UI/PrismUI/layout.json** です。開発用の実行ファイルから保存しても、元のプロジェクトのリソースと現在の実行用コピーを更新します。前のデータは `.bak` に残します。`Reload from resource` で保存済みデータを読み直せます。

画像は **Resources/UI/PrismUI/*.png**、数値用のフォント画像は **font-atlas.png** にあります。プロジェクトのResources/UI以下にPNGを追加し、F4を開き直すと画像一覧に出ます。既存PNGの絵柄を変更した場合はゲームを再起動してください。配置・サイズ・色の変更には再ビルドは不要です。

Debug・Development・Releaseのゲーム表示は同じリソースを使います。エディター自体は既存のステージ・見た目エディターと同じくDebug版で使用できます。

## ゲームとの連動

- `Anchor` は `screen` が画面固定、`title` が開始地点のタイトル、`player` がプレイヤーの突進回数表示、`feedback` が回避・貫通表示に追従する基準点です。Positionはその基準からのずれです。
- スコアやタイムはテキストの `{score}`、`{score6}`、`{time}`、`{rank}`、`{chain}`、`{retries}`、`{pierce}` にゲーム中の値が入ります。
- 標準の見出しや説明はPNGです。文字の絵柄を自由に変えたい場合や日本語にしたい場合はPNGを用意してください。追加テキストと数値は既存の英数字フォント画像で表示します。
- HP・突進回数・ボスHPの表示も配置データに含まれます。`Meter` と `Repeat`、`Repeat gap`、`Empty tint` が数や残量に連動します。
- `replay_button` を動かすと再挑戦のクリック範囲も一緒に移動します。文字や飾りはそれぞれ選択して動かせます。キーボード・コントローラーでの再挑戦も引き続き使えます。
- 開始地点から離れるタイトルのフェード、クリア表示のフェード、リスタート時の暗転は維持しています。`Condition / Animation` は各要素がゲーム中に表示されるタイミングを指定します。

## 確認済み

配置の保存・復元、動的な数値、基準点、HP表示、クリア条件、移動後のボタン判定を自動テストしています。また、エディターへのテスト入力で見出しの移動・サイズ変更・保存・Undoを確認しています。テスト保存はSettings/ui-editor-smoke.jsonに分け、ゲーム用リソースを上書きしません。

開発用テストは `tests/run-ui-layout-tests.cmd`、Debug版の `--spear-ui-interaction-test` で再実行できます。
