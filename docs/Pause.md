# ポーズ

プレイ中に **Esc** またはコントローラーの **START／メニューボタン** を押すとポーズします。同じボタンでも再開できます。

- **↑↓／W・S／十字キー／左スティック**：選択。
- **Enter／Space／A**：決定。
- **Esc／START／B**：再開。
- **R**：ポーズ中もチェックポイントからリトライ。
- **マウス**：項目にカーソルを合わせ、クリックして決定。

「つづける」は停止した場所から再開します。「リトライ」は既存の暗転を挟み、現在のチェックポイントからやり直します。

停止中はプレイヤー、ボス、弾、回復用結晶、粒子、背景の浮遊粒子、ゲームタイマーと効果音を停止します。再開する操作が、そのままジャンプや突進として入力されないようにしています。

クリア演出中、リトライの暗転中、各エディターの操作中はポーズメニューを開きません。

見た目は `Resources/UI/PrismUI/Pause/` のPNGと `Resources/UI/PrismUI/layout.json` で管理しています。**F4 → pause** ページから、見出し・項目・操作案内の位置やサイズを変更できます。ボタンを移動・拡縮するとクリック範囲も追従します。
