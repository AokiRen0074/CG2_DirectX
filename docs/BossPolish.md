# 着弾・反撃・召喚の演出

- 槍雨が床に到達すると、刺さった結晶、短い衝撃波、火花、残光を表示します。着弾音は同時に重なりすぎないよう間隔を空けています。
- 弾が当たった位置にも砕ける破片を追加しました。着弾位置は移動経路と床の交点から求め、速い弾でも接触を取りこぼさないようにしています。
- 4ダメージ以上の強打では、閃光・飛び散る結晶・短い停止で手応えを強調します。
- 攻撃後のボスは装甲が滑らかに開き、核が大きく明るく見える姿勢へ移ります。回転も遅くなり、反撃できる時間が分かりやすくなります。
- 召喚前に結晶と光の輪が集まり、出現時には輪が広がる演出を追加しました。

床に残る衝撃や破片は、約0.5秒で消える演出です。リスタート時にはまとめて消去します。

Debug・Development・Releaseのビルド、着弾と強打の判定、演出の寿命とリセット、ステージ・UI・ゲームループの確認を行っています。F6で第一形態、F7で第二形態を試せます。
