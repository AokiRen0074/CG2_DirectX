# 1シーンで完結するゲームループ

タイトルからプレイ、ボス撃破、結果表示、再挑戦まで、既存のGameSceneの中で動作します。仮タイトルは **PRISM LANCER** です。

## 開始

開始地点の上にタイトルを表示します。開始ボタンは不要で、そのまま動き出せます。タイトルの位置は開始地点の空間に固定され、カメラが進むと画面の左へ離れながら薄くなります。開始地点に戻れば再び見えます。

プレイ中は、HP・スコア・経過時間を表示します。左下の案内文と帯は表示しません。これらはRelease／Developmentでも表示されます。

## クリア

撃破時は短い閃光と放射状ブラー、結晶の破片と衝撃波を表示します。カメラを少し寄せ、上下に黒帯を入れた余韻からクリア結果へ移ります。

結果にはランク、タイム、スコア、最大チェイン、リトライ数を表示します。アプリを起動している間のベストタイムを更新した場合は `NEW SESSION BEST` と表示します。

約2.5秒後に再挑戦の入力を受け付けます。Enter／Space／R／コントローラーA、または結果画面のボタンをクリックすると、約1秒の暗転とフェードインを挟んで、同じシーン内で開始地点へ戻ります。タイトルも再表示され、HP・敵・スコア・タイムは新しいプレイの状態に戻ります。

## 既存の操作

- A/D・左右キー：移動
- Space／コントローラーA：ジャンプ・空中突進
- R：プレイ中はチェックポイントから再挑戦。リトライ数に加算します。こちらも暗転してから再開します。
- F1：Debug版の詳細情報を表示／非表示
- F2：見た目・移動調整
- F3：ステージエディター
- F6/F7：ボス練習／第二形態の練習

エディターを開いている間は、ゲームとタイム計測が止まります。

## ランクの仮基準

- S：リトライ0回、2分30秒以内
- A：リトライ2回以内、4分以内
- B：リトライ5回以内
- C：それ以外

## 確認

進行状態の自動テストと、実際の描画を通した「タイトル→出発→撃破→結果→再挑戦」の一巡テストを追加しています。

Visual Studioのx64 Native Tools Command Promptで `tests\run-game-flow-tests.cmd` を実行すると、進行状態のテストを再実行できます。描画を含む確認は `--spear-loop-smoke-test --spear-capture=保存先フォルダー` で起動します。保存先フォルダーは事前に作成してください。
