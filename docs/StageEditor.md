# チュートリアル・ステージエディター

Visual Studioで **Debug / x64** を選択して起動し、**F3** を押します。`--stage-editor` を指定して起動すると、最初から編集画面が開きます。既存のF2はライト・モデル・移動調整です。

## 編集できるもの

- 足場：7個の位置・幅・高さ。8個目のボス床は固定です。
- 敵：7枠の位置・種類・有効／無効・撃破で開くゲート位置・案内文。
- 開始地点と5つのチェックポイント。
- ボス戦の有無。無効にすると、敵のゲートを通過してX=98に到達した時点でクリアします。

## 基本操作

1. 全体マップの足場・敵・緑色の開始地点／チェックポイントの旗を選択し、ドラッグして配置します。下のSelectionとSlotからも選択できます。
2. 下部の数値入力で微調整します。足場のドラッグでは、その足場に乗っているチェックポイントも一緒に移動します。
3. **Play from start** で編集内容を適用して最初からテストします。再度F3を押すと編集に戻ります。
4. **Save** で保存します。プレイ確認だけではファイルに保存されません。

F3または右上の×で閉じた場合、現在のゲームを再開します。編集内容は下書きとして保持されますが、ゲームに反映するにはPlay from startを押してください。

## 保存と読込

保存先は起動時の作業フォルダー内の `Settings/tutorial-stage.json` です。編集画面にフルパスが表示されます。Visual Studioの標準設定では `artifacts/bin/x64/Debug/Settings/tutorial-stage.json` になります。

次回起動時に自動で読み込みます。**Load** で再読込でき、**Built-in tutorial** で初期配置を下書きに戻せます。既存ファイルへの保存時は、直前の版を `tutorial-stage.json.bak` に残します。

DebugとDevelopment／Releaseでは実行フォルダーが異なります。配布する場合は、保存したファイルを配布先の `Settings` フォルダーへコピーしてください。編集画面はDebug構成のみ有効です。

## 制約

- 現版は固定枠方式です。足場・敵の枠数追加、ステージの横幅拡張には対応していません。
- チェックポイントは左から右へ順に並べ、足場の上面と同じYに置きます。足場の端から0.5以上離してください。
- 敵のゲートは、その敵より1以上右に置きます。
- 不正な座標や空中の復帰地点などは保存・プレイを止め、画面下部に理由を表示します。ジャンプで実際に到達できるかはプレイで確認してください。
- 案内文は現在のフォントに合わせて英語で入力します。日本語フォントの追加は含んでいません。

## 検証

Debug／Developmentビルド、Debug版編集画面の起動・描画・終了を確認しました。配置データのシリアライズ、不正データ拒否、足場判定、復帰地点、敵の再配置、ゲート、案内文、ボスなしクリア、ボス戦への移行を自動テストしています。
