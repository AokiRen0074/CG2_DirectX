# ステージ配置エディター

Visual Studioで **Debug / x64** を起動し、**F3** を押します。編集している間はゲームが止まります。

## 配置する

- **Place floor** を選び、マップをクリックすると床を追加します。
- **Place enemy** を選び、マップをクリックすると敵を追加します。敵は一種類で、倒すと空中ジャンプが1回回復します。
- **Place checkpoint** を選び、床の上をクリックするとチェックポイントを追加します。
- **Select** に戻すと、配置済みのものを選択・ドラッグできます。

床は中央をつかむと移動し、両端の黄色い丸をつかむと幅を変えられます。下の数値欄でも位置・幅を調整できます。床の上にある開始地点・チェックポイントは、床と一緒に移動します。

**Duplicate** で選択物を複製、**Delete selected** で削除します。**Undo / Redo** で編集を戻したり、やり直したりできます。最初のSTARTとボス戦用の床は削除できません。

## ボス開始位置

オレンジの **BOSS START** 線をドラッグします。下の **Selection → Boss start** から **Boss start X** を入力しても変更できます。

開始線を動かすと、ボス用の床、ボスの移動範囲、カメラ、弾・レーザー・予告、ボス戦での再開地点がまとめて移動します。戦闘エリアの床は幅32・高さ-3を保ちます。前の床との接続は配置して調整してください。

**Boss enabled** を外すと、開始線がステージのゴールになります。

## マップ操作

- ホイール：拡大・縮小。
- マウス中央ボタンを押してドラッグ：マップ移動。
- **Fit stage**：ステージ全体を表示。
- **Snap / Grid**：配置間隔をそろえる。

追加した敵は、最初は道をふさぎません。倒すまで先に進めない敵にする場合は、その敵を選んで **Blocks path until defeated** を有効にし、**Gate X** を設定します。

開始地点・チェックポイントは床の上に置き、左から順に並べます。**Snap to floor** で床へ合わせられます。床を削除して開始地点やチェックポイントが宙に浮いた場合は、位置を修正するか、不要なチェックポイントを削除してください。保存・試遊できない理由は下に表示されます。

## 保存と試遊

- **Play from start**：編集中の配置を適用して、最初から遊ぶ。
- **Test boss**：編集中のボス位置で戦闘を試す。
- **Save**：配置を保存する。
- **Load**：保存した配置を読み込む。
- **Built-in tutorial**：元のチュートリアルを下書きに戻す。Saveするまでは保存済み配置を置き換えません。

編集内容はPlayするまでゲーム本体に反映されません。F3で閉じただけなら元のプレイを続けます。

開発中の保存先は、リポジトリの `Resources/Stages/tutorial-stage.json` です。起動中のゲームにもコピーし、次のビルドでは他の構成へも配布されます。保存前のファイルは `.bak` に残します。以前の `Settings/tutorial-stage.json` も、新しいリソースがない場合は読み込みます。

配置上限は床512個・敵256体・開始地点を含むチェックポイント64個です。床の配置範囲はX=-256〜2048、上面Y=-8〜10です。
