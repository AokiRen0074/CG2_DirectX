# ボス攻撃の強化

HPを増やす代わりに、攻撃の波数、技の切り替え、予告、反撃の時間を調整しています。

- 扇状弾：第一形態は7発×3波、第二形態は9発×4波。交互に角度をずらし、弾の間を動いて避ける攻撃にしました。
- 槍雨：第二形態で3波に分けて落下。2列分の安全な通路が波ごとにずれます。後続の波も落下前に予告線を表示し、その間はダメージ判定がありません。
- 連続突進：第二形態は3連続。各突進は直前に狙いを固定します。通過範囲の予告と残像・光跡を追加しました。
- 掃射ビーム：第一形態より第二形態で広く掃射します。予告と実際の当たり判定は同じ角度範囲・線分を使います。
- 新しい大技：第二形態で、隙間の向きが少しずつ変わる全方位弾を3波放ちます。装甲が開く溜め、周囲の結晶、発射時の閃光、放射状の光跡を追加しました。隙間の境界と次の波の予告も表示します。

技の間の移動を速め、待ち時間を短縮しました。攻撃終了後は弾を消して反撃の時間を作り、全方位弾の後は少し長い隙を設けています。ボスのHPは72のままです。

F6で第一形態、F7で第二形態の練習に入れます。これまでのプレイヤー操作・ステージ・リザルトは維持しています。

## 確認

自動テストでは、扇状弾の波数と弾の上限、安全な雨の通路、予告中の無判定と発射後の判定、全方位弾の隙間、3連続突進、第二形態への移行、攻撃終了後の反撃時間を確認しています。

Debug・Development・Releaseでビルドし、実際の画面で各攻撃と撃破後のクリア・再挑戦まで確認しています。

テストは `tests/run-boss-tests.cmd` で再実行できます。全方位弾の撮影は `--spear-nova-smoke-test --spear-capture=保存先フォルダー` で行えます。保存先フォルダーを先に作成してください。
