# ゲーム内の立体物とOBJ

これまでコードで立体風に描いていた弾・破片・浮遊結晶・光粒の本体を、Blenderで作成したOBJの読み込みへ変更しました。回復用結晶にも専用OBJを用意しました。

新しいファイルはリポジトリの `Resources/AL4/Effects/` にあります。

| ファイル | 用途 |
| --- | --- |
| `effect_shard.obj` | 破片、浮遊結晶、ボスの周囲の小さな結晶、残像の結晶部分 |
| `crystal_projectile.obj` | 扇状弾・全方位弾の本体 |
| `lance_projectile.obj` | 落下する槍弾の本体 |
| `ambient_grain.obj` | 空中の粉、ダッシュや命中時の小さな粒の本体 |
| `refill_crystal.obj` | ボス戦のジャンプ回数を回復できる結晶 |
| `GameplayEffects.blend` | 上記5種類を編集できるBlenderファイル |

それぞれMTLを同じフォルダーに置いています。モデルの形状はOBJ、面の色はMTLから読み込みます。エフェクトの青・橙などの色はゲーム側の色と掛け合わせます。移動・回転・寿命はこれまでどおりゲーム側で制御します。

粒子はモデルデータを共有し、まとめて描画します。1粒ごとにファイルを読み直す処理はありません。

プレイヤー、槍、床、背景結晶、ボス、通常の敵、ゲートなどは、既存のOBJを引き続き使っています。光のにじみ、ビームの発光、軌跡、攻撃の予告線は、モデルに重ねる光の演出として描画しています。

5種類とも厚みのある閉じたメッシュで、三角形・法線・MTL参照を検証しています。Blenderで編集した場合はOBJを書き出して置き換え、ゲームを再起動すると読み込み直します。
