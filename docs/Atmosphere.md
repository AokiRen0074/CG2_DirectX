# 空中の浮遊粒子

淡い光の粉と小さな結晶片を追加しました。奥・中間・手前の3層で大きさと視差を変え、ゆっくり上へ漂わせています。粒は少しずつ明滅し、端で薄く消えます。

背景の図形やステージ配置は維持しています。プレイヤーの近くとボス戦中は粒子を薄くし、攻撃や残りジャンプ回数を読みやすくしています。

DebugでF2を開き、**Atmosphere** から調整できます。

- **Floating crystal dust**：表示のオン・オフ。
- **Dust density**：粒の量。初期値1、最大2。
- **Dust brightness**：明るさ。初期値1、最大2。
- **Drift speed**：漂う速さ。初期値1。
- **Save**：調整を保存。

F2でゲームを止めても浮遊粒子は動くため、見ながら調整できます。以前のエフェクト設定ファイルも引き続き読み込めます。

# ボスの変更

地面を燃やす攻撃を両形態から削除しました。攻撃予告、ダメージ判定、床の亀裂・噴出光・残光と、試作用の切り替えも削除しています。扇状弾、突進、召喚、掃射ビーム、第二形態の槍雨と全方位弾は残しています。

両形態をそれぞれ6000フレーム動かし、地面攻撃が生成されないことを確認しています。
