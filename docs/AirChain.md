# 空中連撃の流れ

敵を倒すことが、次の移動と攻撃につながるように調整しました。

- 空中で敵を倒すと突進回数が1回回復します。突進の貫通は止めず、終了後に約0.23秒の滞空を残して次を狙いやすくしました。方向を入れて次の突進を出すと、すぐに移動します。
- 着地せず2体以上倒すと「追撃強化」。そのままボスに突進すると、2体で4、3体以上で6の追加ダメージが入ります。蓄えた強化はその一撃で消費し、突進回数も1回戻ります。
- 着地・被弾で連続撃破と強化はリセット。着地による通常の全回復は維持しています。リザルトの連続撃破評価も、着地せずつないだ最大数になります。
- 連続撃破に応じて回復音の音程が上がります。強化中はプレイヤーとボスに薄い青い輪が出ます。
- 長い穴に敵を1体追加し、手前の足場に復帰地点を追加。落下・死亡・リトライで移動に必要な敵が復活します。
- ボスの攻撃終了時にも、消費された回復用の敵を補充。生きている敵の位置は動かしません。

操作は従来どおりです。地上でSpace / Aがジャンプ、空中で方向＋Space / Aが突進です。新しい自動照準や専用ボタンは追加していません。

表示はResources/UI/PrismUI/layout.jsonとAirChain内のPNGで管理しているため、F4の既存UIエディターで配置を調整できます。床・敵・復帰地点はF3で変更できます。

## 確認

残り1回から3体の撃破とボスへの強化攻撃、実際に生成する第一・第二形態のルート、短い滞空と即座の次入力、追加ダメージの再利用防止、着地・被弾によるリセット、通常ジャンプから5体の連続撃破と対岸への着地、失敗後の敵復活を自動テストで確認しています。
