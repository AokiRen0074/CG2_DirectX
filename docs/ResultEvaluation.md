# リザルトの変更

結晶のランク章、斜めの背景装飾、英語の小見出し、ベスト更新、成績の細かい一覧、フッターを結果画面から外しました。

左に五角形の評価チャート、右にクリア・総合評価・タイム・スコア・再挑戦だけを表示します。チャートが伸びてから、総合ランクを拡大から止める動きと短い効果音で表示します。タイムやスコアの数え上げは止めました。

## 5項目の仮基準

各項目を1〜5で評価し、その合計からD / C / B / A / Sを決めます。チャートの値は実際のプレイ記録です。

|項目|2点|3点|4点|5点|
|---|---:|---:|---:|---:|
|攻撃：有効な攻撃の命中回数|3回|6回|10回|15回|
|回避：ジャスト回避の成功回数|1回|3回|5回|8回|
|速さ：クリアタイム|5分以内|3分30秒以内|2分30秒以内|1分30秒以内|
|貫通：1回の攻撃で当てた最大数|2体|3体|4体|5体|
|連撃：最大チェイン|2|4|6|8|

2点の基準に届かなかった項目は1点です。攻撃の命中は敵・召喚された敵・ボスへの有効な命中を数えます。チェックポイントからの再挑戦では記録を引き継ぎ、最初からの再挑戦でリセットします。

総合ランクは合計23以上がS、18以上がA、13以上がB、8以上がC、それ未満がDです。仮基準はApplication/Character/SpearGameFlow.hのSpearRunEvaluationで調整できます。

## 編集

チャートの背景と日本語ラベルは `Resources/UI/PrismUI/Radar/`、位置・サイズ・色は既存の `Resources/UI/PrismUI/layout.json` にあります。チャートの線・面は実際の評価から描きます。F4のUIエディターでも位置とサイズ、色を調整できます。

チャートは `Meter: evaluation` と `Animation: chart`、総合ランクは `Animation: rank` で指定しています。再挑戦前にはランクを見せる時間を取り、再挑戦時の暗転は維持しています。
