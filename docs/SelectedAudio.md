# 選択した音の組み込み

既存の突進・命中・被弾・回復・撃破音を残し、選択された音を追加しました。

| 用途 | 選択した音源 |
|---|---|
| タイトル・道中 | Outer Space Loop / wipics |
| ボス戦 | Electric Stream / Alexander Ehlers（激しい戦闘の別案） |
| 着地 | impactGeneric_light_002 |
| 強化攻撃の命中 | impactMetal_heavy_000 |
| チェックポイント | confirmation_004 |
| 扇状弾の発射 | laserSmall_000 |
| レーザーの発射 | laserLarge_000 |
| 項目の選択 | click_003 |
| 決定 | confirmation_001 |
| 戻る | back_001 |

タイトル曲は道中で音量を抑え、ボス戦へ入ると戦闘曲へフェードで切り替えます。戦闘曲のループのつなぎ目も整えました。クリア時はBGMをフェードアウトします。

ポーズ中はBGMと戦闘音を止め、再開すると同じ位置から続きます。ポーズ中の項目移動・決定・戻るの音は鳴ります。リトライ時は古い戦闘音を消し、暗転に合わせてBGMの音量も下がります。

音量は効果音が埋もれないようBGMを控えめにしています。追加した効果音と元の音は別々の再生枠で管理しています。

素材は Resources/Audio/Selected にPCM WAVとして保存しています。配布元・作者・CC0表記・変換内容は sources.json、同梱の利用条件と配布ページの記録は Licenses に保存しました。

元の候補番号：M01、M05、S03、S08、S11、S14、S15、S21、S22、S23。
