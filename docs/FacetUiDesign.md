# PRISM LANCER / Facet UI

青い結晶のプレイヤー、暖色のボス、シンプルな背景に合わせて、HUD・タイトル・リザルトを作り直しました。既存のUIエディターで調整できるPNGと配置データで実装しています。

## 調べたリファレンス

### Returnal

[PlayStation公式ブログ：ReturnalのUX設計](https://blog.playstation.com/2021/05/11/unpacking-returnals-ux-design-gameplay-first-ui-retro-futuristic-tech-and-accessibility/)

開発者による「ゲームプレイを優先し、重要な情報をプレイヤーの視点付近、それ以外をHUDの周辺へ置く」という説明と、青緑を中心とした機能的なUIを参考にしました。

本作では、左上にHP、右上にタイムとスコア、プレイヤー付近に残り突進回数を集約しました。画面中央はアクションに使えるよう空け、HPが少ない場合はHPゲージを赤くします。ボスHPは敵の発光色に合わせて暖色にしています。

### Neon White

[実際のリザルト画面とデザイン考察](https://mimidoshima.neocities.org/notebooks/posts/2024-05-08-%5BDCB%5D%20Neon%20White) / [国内販売元の公式資料](https://happinet-games.com/release/240919NW/happinet0919_NW.pdf)

大きなクリア見出し、目立つクリアタイム、メダルを使った結果の祝福、左右に役割を分けた構成を参考にしました。

本作では左に独自の結晶ランク章、右にクリアタイム・セッションベスト・スコア・最大チェイン・リトライ数を配置。再挑戦ボタンを明るいシアンで強調しました。キャラクターや装飾画像は参考作品から流用せず、本作の結晶モチーフに合わせた図形と文字画像を用意しています。

## 実装した見た目と動き

- タイトル：結晶アイコン、余白のあるロゴ、短い操作案内。開始地点に固定され、離れると薄くなる動作を維持。
- HUD：暗い小型パネル、斜めに切ったHPゲージ、コンパクトなタイムとスコア。左下の案内文は追加していません。
- リザルト：左の結晶ランク章と右の成績を分離。クリアタイムを最大の数値にし、セッションベストも表示。
- 演出：見出し、ランク章、成績の順に表示。タイムとスコアを数え上げた後に再挑戦を受け付けます。
- 再挑戦：既存の約1秒の暗転・フェードインを維持。

## リソースと編集

- 配置：`Resources/UI/PrismUI/layout.json`
- 新しい画像：`Resources/UI/PrismUI/Facet/`（35枚）
- 数値用フォント：既存の `Resources/UI/PrismUI/font-atlas.png`

Debug版で **F4** を押すとUIエディターを開けます。画像・位置・サイズ・色・表示条件などを調整し、**Ctrl+S** で保存できます。タイトル・HUD・ボス・撃破演出・リザルト・暗転のプレビューを切り替えられます。

新しい `rank / stats` のAnimationはランク章・成績の表示タイミング、`lowHealth` のConditionはHP低下時の表示、`{bestTime}` は起動中のベストタイムに対応しています。

## 動作確認

Debug・Development・Releaseでビルドし、ゲーム本体でタイトル→ボス戦→撃破→リザルト→暗転→再挑戦を確認しています。配置データの保存・復元、動的数値、HP、表示条件、移動後のボタン判定、およびエディターへのテスト入力による移動・拡縮・保存・Undoも確認しています。
