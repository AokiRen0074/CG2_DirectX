# 空中ジャンプを使う機会の追加

ボスが出す回復用の相手を、水色の結晶に変更しました。触れてもダメージや無敵時間は発生しません。攻撃で壊すと、従来どおり空中ジャンプが1回回復します。

召喚時だけでなく、扇状弾・掃射ビーム・槍雨・全方位弾の予告中にも出現します。プレイヤーからボスへ近づく足がかりになるよう、第一形態は3個、第二形態は4個を空中に配置します。近距離では横へ回り込める配置になります。

まだ残っている結晶は動かし直さず、使った分だけ次の攻撃予告で補充します。接触しても安全ですが、周囲のボスの弾や攻撃は避ける必要があります。

ボス直前には任意の上段ルートを追加しました。3体の敵を別々の空中ジャンプで倒して回数を回復し、上段からボスエリアへ入れます。従来の地上ルートも使えます。F3で追加した床と敵も移動・削除できます。

検証では、接触時にHP・無敵時間が変わらないこと、攻撃で回復すること、空中で結晶をつないで移動できること、予告ごとの補充、残っている結晶が移動しないこと、追加した上段ルートの通過を確認しています。
